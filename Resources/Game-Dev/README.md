# Game Development Learning Resources

Curated resources and tutorials to guide you from absolute beginner to publishing your first game.

## Week 1 - Game Dev Fundamentals (Unity / Unreal / Godot)
* [Unity Essentials Pathway](https://learn.unity.com/pathway/unity-essentials) - Official beginner pathway covering Unity basics and interface.
* [Unreal Engine 5 Beginner Tutorial](https://www.unrealengine.com/en-US/onlinelearning-courses/unreal-engine-5-getting-started) - Official introduction to Unreal Engine 5 workflows.
* [Godot Getting Started Guide](https://docs.godotengine.org/en/stable/getting_started/step_by_step/index.html) - Comprehensive introduction to Godot Engine concepts and nodes.

## Week 2 - C# / C++ for Games
* [Microsoft C# Guide for Beginners](https://learn.microsoft.com/en-us/dotnet/csharp/tour-of-csharp/) - Official documentation and tour of the C# language used in Unity.
* [LearnCPP.com](https://www.learncpp.com/) - Free, in-depth tutorial site for mastering C++ for Unreal Engine development.
* [C# Scripting in Unity Tutorial](https://learn.unity.com/course/create-with-code) - Hands-on guide to applying C# scripts to game objects.

## Week 3 - Game Design Principles
* [Extra Credits (YouTube Series)](https://www.youtube.com/user/ExtraCreditz) - Bite-sized video essays covering game design theory, mechanics, and psychology.
* [Game Maker's Toolkit (YouTube)](https://www.youtube.com/c/GameMakersToolkit) - Deep dives into game design, level design, and accessibility.
* [The Art of Game Design: A Book of Lenses](https://www.gamedesignbook.org/) - Foundational principles and questions for shaping great game mechanics.

## Week 4 - Publishing & Portfolio
* [itch.io Creator Guide](https://itch.io/docs/creators) - Step-by-step documentation on how to publish indie games and build a developer profile.
* [Steamworks Documentation Overview](https://partner.steamgames.com/doc/home) - Introduction to the backend and publishing process on Steam.
* [Building a Game Dev Portfolio](https://gamedev.net/) - Guide on how to showcase your projects effectively to studios or the community.
